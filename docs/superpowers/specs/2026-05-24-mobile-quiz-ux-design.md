# 모바일 퀴즈 UX 설계

## 목표

모바일 화면에서도 사용자가 스크롤 부담 없이 바로 문제를 읽고 답을 제출할 수 있게 한다. 데스크톱의 3컬럼 학습 도구 레이아웃은 유지하고, 작은 화면에서는 문제 풀이 흐름을 우선 배치한다.

## 문제점

- 현재 모바일 레이아웃은 필터, 문제, 요약 순서로 쌓여 문제 풀이 시작 전 스크롤이 길다.
- 채점, 이전, 다음 버튼이 문제 하단에만 있어 반복 풀이 중 조작 위치가 흔들린다.
- 상단 점수 영역이 모바일에서 세로로 길어져 첫 화면에서 문제 노출이 늦어진다.
- 객관식, O/X, 매칭, 순서 입력은 터치 대상 간격이 더 커야 한다.

## 설계

- 모바일에서는 그리드 영역 순서를 문제, 요약, 필터 순으로 바꾼다.
- 모바일 상단 점수 영역은 3열 압축 상태 바 형태로 유지한다.
- 문제 패널 패딩과 제목 크기를 모바일 폭에 맞춰 줄인다.
- 답안 옵션은 최소 터치 높이를 키우고 라디오/체크 입력이 눌리기 쉽게 한다.
- 액션 버튼 영역은 모바일에서 화면 하단에 sticky로 고정한다.
- sticky 액션 바가 본문을 가리지 않도록 앱 하단 여백을 추가한다.
- 필터와 요약은 모바일에서도 접근 가능하되 풀이 흐름 뒤에 배치한다.

## 검증 기준

- 기존 퀴즈 풀이 테스트가 통과한다.
- 모바일 액션 바 영역은 `aria-label="문제 이동과 채점"`으로 식별 가능해야 한다.
- `npm test`와 `npm run build`가 성공해야 한다.
- Chrome 기반 모바일 뷰포트에서 배포 페이지가 렌더링되고 첫 화면에 문제 제목과 하단 액션 바가 보여야 한다.
