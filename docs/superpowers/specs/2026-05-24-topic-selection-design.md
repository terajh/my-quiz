# 주제 선택형 퀴즈 설계

## 목표

현재 하나의 쿠버네티스 퀴즈만 제공하는 앱을 여러 퀴즈 주제를 선택할 수 있는 구조로 바꾼다. 사용자는 첫 화면에서 원하는 주제를 고르고, 선택한 주제의 문제만 풀 수 있어야 한다.

## 데이터 모델

- `QuizTopic` 타입을 추가한다.
- 각 주제는 `id`, `title`, `description`, `sourceLabel`, `questions`를 가진다.
- 기존 쿠버네티스 문제 배열은 `kubernetes` 주제의 `questions`로 이동한다.
- 주제 목록은 `quiz-topics.ts`에서 `quizTopics`로 export한다.

## 화면 동작

- 상단에는 선택된 주제의 `sourceLabel`과 `title`을 표시한다.
- 필터 패널 최상단에 `주제` select를 추가한다.
- 주제를 변경하면 섹션 필터, 유형 필터, 오답 모드, 현재 문제 인덱스, 임시 답안을 초기화한다.
- 하나의 주제만 있어도 주제 select는 노출한다. 이후 주제를 추가할 때 UI 변경 없이 데이터만 추가할 수 있게 한다.

## 풀이 기록

- 풀이 기록은 주제별로 분리한다.
- 저장소 키는 `myquiz-progress:<topicId>` 형식을 사용한다.
- 주제를 바꾸면 해당 주제의 저장 기록을 로드한다.
- 기록 초기화는 현재 선택된 주제의 기록만 삭제한다.

## 검증 기준

- 주제 데이터는 ID가 중복되지 않고 각 주제에 문제가 하나 이상 있어야 한다.
- 기존 쿠버네티스 문제 수와 문제 유형 커버리지는 유지한다.
- 주제별 저장소 키가 분리되어 한 주제의 기록이 다른 주제에 섞이지 않는다.
- UI에서 주제 select가 보이고, 선택된 주제의 제목과 출처가 표시된다.
- `npm test`와 `npm run build`가 성공해야 한다.
